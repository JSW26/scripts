# Base64 드래그 디코더 — 변경 이력

배포 중인 스크립트: [Base64_Drag_Decoder.user.js](./Base64_Drag_Decoder.user.js)

> GitHub를 통한 체계적인 기록은 2026-11-13부터 시작했습니다. 이전 개발 이력의 날짜와 세부 내용은 일부 부정확할 수 있습니다. 보관 버전은 자동 업데이트 대상이 아닙니다.

**현재 적용 사이트:** 모든 HTTP(S) 웹사이트 (v1.2.0부터 사이트별 제외 없음)

### 1.2.0 — 2026-11-13
**변경 배경:** 선택 텍스트 디코더는 다른 자동 해독 스크립트와 독립적으로 사용되는 경량 도구이며, 특정 사이트를 제외할 필요가 없습니다.

**변경 사항**
- 특정 도메인의 `@exclude` 설정을 삭제했습니다.
- 같은 도메인을 차단하던 코드 내부 호스트 검사와 조기 종료 조건을 제거했습니다.
- 선택한 Base64 문자열을 디코딩하고 결과를 복사하는 기존 기능은 유지했습니다.
- 다른 자동 해독 스크립트와 병행 사용할 수 있도록 전체 HTTP(S) 페이지 범위를 허용했습니다.

**검증 및 제한:** GitHub 소스 반영 및 적용 범위 확인 완료. 실제 브라우저별 동작은 별도 검증되지 않았습니다. 브라우저의 내부 페이지나 확장 프로그램 페이지에서는 사용자 스크립트 실행이 제한될 수 있습니다.

[버전 소스](history/v1.2.0.user.js)

### 1.1.0 — 2026-11-08 ~ 11-09
**변경 배경:** 콘텐츠 자동 해독 도구와 선택 텍스트 디코더가 동일한 적용 대상에서 중복 실행될 수 있었습니다.

**변경 사항**
- 일부 적용 대상에 `@exclude` 및 호스트 검사를 추가해 기능 중복을 방지했습니다.

[버전 소스](history/v1.1.0.user.js)

### 1.0.0 — 2026-11-04
- 기존 선택 텍스트 디코딩 기능을 복원했습니다.
- 선택한 Base64 문자열을 UTF-8 텍스트로 해독하고 결과 표시·복사 UI를 구성했습니다.

[버전 소스](history/v1.0.0.user.js)
