# 이미지 자동 복구 — 변경 이력

배포 중인 스크립트: [Kone_Image_Recovery.user.js](./Kone_Image_Recovery.user.js)

> GitHub를 통한 체계적인 기록은 2026-11-13부터 시작했습니다. 이전 개발 이력의 날짜와 세부 내용은 일부 부정확할 수 있습니다. 보관 버전은 자동 업데이트 대상이 아닙니다.

**적용 사이트:** `kone.gg` (일부 과거 버전은 게시글 경로로 제한)

### 0.3.5 — 2026-11-13

**변경 배경:** 장시간 방치하거나 SPA 방식으로 다음 게시글에 이동한 직후, 첫 번째 이미지의 오류 기록이 초기화되어 이후 이미지와 달리 복구되지 않는 현상이 반복되었습니다.

**변경 사항**
- SPA 경로 변경을 실패 이미지 기록보다 먼저 처리하여 첫 이미지 오류 기록이 삭제되지 않도록 보완했습니다.
- 탭 가시성 복귀 및 포커스 회복 시 화면 주변의 손상된 이미지를 다시 검사합니다.
- 이전 게시글에서 시작한 비동기 복구 결과가 새 게시글의 복구 상태에 적용되지 않도록 경로 세대 검사를 추가했습니다.
- 기존 UI 없는 자동 복구 방식과 갱신 URL은 그대로 유지했습니다.

**검증:** 사용자 환경에서 `0.3.5-beta.1` 시험판의 정상 작동을 초기 확인받았으며, 요청에 따라 정식 버전으로 승격했습니다. 장기 반복 테스트는 아직 완료되지 않았습니다. 정식 배포에서 복구 알고리즘은 바꾸지 않았습니다.

[버전 소스](history/v0.3.5.user.js)

### 0.3.4 — 2026-11-13

**변경 배경:** 화면 우측 하단의 이미지 복구 UI가 콘텐츠 열람을 방해하며, 자동 복구 동작에는 별도 제어 패널이 필요하지 않았습니다.

**변경 사항**
- 고정형 UI 패널과 수동 복구·진단 복사·접기 버튼을 제거했습니다.
- 패널 생성 및 재부착용 `MutationObserver`를 제거했습니다.
- 패널의 상태 텍스트 대신 복구 진행 상태를 개발자 콘솔에 기록하도록 변경했습니다.
- 오류 감지, 이미지 주소 재조회, 자동 재시도, SPA 경로 전환 감지 등 자동 복구 경로를 유지했습니다.
- 표시 UI를 제거하되 실제 복구 이미지를 원본 콘텐츠에 표시하는 오버레이 처리는 유지했습니다.

**검증:** `0.3.4-beta.1`을 통해 사용자 환경에서 테스트 후 정상 동작을 확인받아 정식 버전으로 승격했습니다. 정식 배포 시 승인된 Preview 코드의 동작은 변경하지 않고 버전 표기만 수정했습니다.

[버전 소스](history/v0.3.4.user.js)

### 0.3.3 — 2026-11-10
**변경 배경:** 여러 도구의 조작 UI가 서로 다른 영역에 분산되어 배치 일관성이 저하되었습니다.

**변경 사항**
- 복구 패널을 화면 우측 하단에 도킹하도록 변경했습니다.
- 다른 상태 표시 요소와의 배치를 조정했습니다.
- 이미지 복구 알고리즘은 이전 버전의 동작을 유지했습니다.

[버전 소스](history/v0.3.3.user.js)

### 0.3.2 — 2026-11-08 ~ 11-09
**변경 배경:** 장시간 비활성 상태 이후 처음 표시되는 이미지 한 개가 복구되지 않고 후속 이미지만 복구되는 사례가 관찰되었습니다.

**변경 사항**
- 이미지 요소가 대체 표시로 전환되더라도 기존 요청 URL을 추적할 수 있도록 `WeakMap`을 추가했습니다.
- 이미지 후보 탐색 및 인덱스 매칭 절차를 보완했습니다.
- 최소 재탐색 간격을 25초에서 8초로 줄였습니다.

**잔여 문제:** 첫 이미지 복구 실패 현상의 완전한 해결 여부는 확인되지 않았습니다.

[버전 소스](history/v0.3.2.user.js)

### 0.3.1 — 2026-11-08 ~ 11-09
**변경 배경:** UI 충돌과 SPA 화면 전환 이후 패널이 사라지는 문제가 발생할 수 있었습니다.

**변경 사항**
- 패널 위치를 조정해 다른 기능의 UI와 분리했습니다.
- 수동 복구, 진단 정보 복사, 접기·펼치기 제어를 추가·정리했습니다.
- 화면 재렌더링 이후 패널을 다시 부착하도록 처리했습니다.
- 패널이 접힌 상태에서도 복구 처리는 지속하도록 구성했습니다.

[버전 소스](history/v0.3.1.user.js)

### 0.3.0 — 2026-11-06
**당시 적용 범위:** `kone.gg/s/*` 게시글 경로 및 대응하는 `www` 하위 도메인

**변경 배경:** 이미지 URL의 유효 기간이 만료되면 기존 주소로 요청을 다시 보내도 HTTP 403 오류가 발생할 수 있었습니다.

**변경 사항**
- 실패한 이미지의 기존 주소와 실패 내역을 기록했습니다.
- 대상 페이지의 최신 문서 데이터를 다시 조회해 갱신된 이미지 URL을 탐색하도록 했습니다.
- 가능한 경우 실패한 이미지 요소의 주소만 교체해 스크롤 위치 및 펼침 상태를 유지했습니다.
- 요청 횟수 제한, 재실행 간격, 복구 상태 진단을 추가했습니다.

[버전 소스](history/v0.3.0.user.js)

### 0.2.0 — 2026-11-06
- 실패 이미지 URL을 기록하고 제한된 범위에서 재시도하는 처리를 강화했습니다.
- 필요한 경우 화면 상태를 보존하는 새로고침 절차를 사용했습니다.

[버전 소스](history/v0.2.0.user.js)

### 0.1.0 — 2026-11-05
- 지연 로딩된 이미지의 수동 재시도 기능을 추가했습니다.
- 스크롤 위치와 `details` 펼침 상태를 `sessionStorage`에 저장·복원했습니다.
- URL 만료에 따른 새 주소 갱신 기능은 포함하지 않았습니다.
