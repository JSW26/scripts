# Kio → Kiosk Downloader 연동

Windows Bridge와 연동해 Kiosk Downloader로 링크를 전달.

- **현재 버전:** `1.2.0`
- **적용 사이트:** `kio.ac`
- [최신 소스](Kio_to_Downloader_v1.2.0.user.js) · [Tampermonkey 설치](https://raw.githubusercontent.com/JSW26/scripts/main/scripts/kio-downloader/Kio_to_Downloader_v1.2.0.user.js)
- [업데이트 로그](CHANGELOG.md) · [과거 버전 소스](history/)
- [Windows Bridge 최초 설치](bridge/README.md) — `bridge/install.cmd` 실행 필수. Bridge 버전 `1.2.0`. 1.1.x 및 베타 1 사용자는 브릿지를 업데이트하세요. 베타 2 사용자는 정식 스크립트만 설치하면 됩니다.

- `update.meta.js`: Tampermonkey의 버전 확인용 정보 파일(실행 스크립트가 아님)
