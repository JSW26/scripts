# 통합 자동 디코더 — 변경 이력

배포 중인 스크립트: [Kone_Unified_Decoder.user.js](./Kone_Unified_Decoder.user.js)

> GitHub를 통한 체계적인 기록은 2026-11-13부터 시작했습니다. 이전 개발 이력의 날짜와 세부 내용은 일부 부정확할 수 있습니다. 보관 버전은 자동 업데이트 대상이 아닙니다.

**적용 사이트:** `kone.gg` · `kio.ac` (두 사이트 및 메타데이터에 지정된 하위 도메인)

### 4.0.0 — 2026-11-08 ~ 11-09
**변경 배경:** 서로 다른 디코더의 기능이 중복되고, 여러 사용자 스크립트의 UI 및 이벤트 처리 간섭이 발생할 수 있는 구조를 개선할 필요가 있었습니다.

**변경 사항**
- 다중 Base64, 점자 및 SecureEncoder 기반 해독 기능을 통합했습니다.
- 링크 목록, 비밀번호 전달 및 자동 입력, 댓글 텍스트 인코딩, 빠른 복원 등 기존 편의 기능을 통합했습니다.
- 해독 결과의 문단별 표시·숨김 처리와 자동 링크 인식을 보완했습니다.
- 별도 리소스 복구 도구와 상태 UI가 겹치지 않도록 반투명 UI를 조정했습니다.
- 일반 페이지용 선택 텍스트 디코더는 적용 범위가 겹치지 않도록 별도 유지했습니다.

**검증 및 제한:** 자동화된 일부 테스트 산출물은 존재하지만, 모든 브라우저 및 인증 상태에서의 검증을 의미하지는 않습니다.

[버전 소스](history/v4.0.0.user.js)

### 3.2.0 — 2026-11-06
**변경 배경:** 독립적인 사용자 스크립트의 상태 패널이 동일한 화면 영역에 표시되었습니다.

**변경 사항**
- 상태 표시 UI를 반투명 형태로 정리했습니다.
- 주변 패널의 크기 및 표시 상태에 따라 상태 표시 위치를 동적으로 조정했습니다.
- 패널 접기·제거 시 기존 위치로 복귀하도록 처리했습니다.

[버전 소스](history/v3.2.0.user.js)

### 3.1.0 — 2026-11-05
**변경 배경:** 대량의 콘텐츠 해독과 브라우저 탐색 시 중복 처리로 인한 지연이 발생했습니다.

**변경 사항**
- 세션 및 메모리 캐시를 추가했습니다.
- 동일 입력·실패 항목의 불필요한 재복호화를 줄였습니다.
- DOM 스캔의 중복 작업 및 재검사 간격을 최적화했습니다.
- 실행 시점을 `document-end`로 조정했습니다.

[버전 소스](history/v3.1.0.user.js)

### 3.0.1 — 2026-09-21
**변경 배경:** SPA(Single-Page Application)의 경로 전환 이후 이전 페이지의 해독 상태가 남는 문제를 방지할 필요가 있었습니다.

**변경 사항**
- 경로 변경 시 토큰 위치 추적 상태(`tokenHomePath`)를 초기화하도록 수정했습니다.

[버전 소스](history/v3.0.1.user.js)

### 3.0.0 — 2026-09-21
**변경 배경:** 텍스트 해독과 비밀번호 입력 보조 기능을 개별 스크립트로 관리하던 구조를 통합했습니다.

**변경 사항**
- SecureEncoder 및 Base64 자동 해독을 결합했습니다.
- 연결된 페이지의 암호 전달 및 입력 보조 기능을 포함했습니다.

[버전 소스](history/v3.0.0.user.js)

### Legacy 2.3.0 — 2026-09-19

**적용 범위:** `*.kone.gg` (당시 전신 버전 기준)
- 인코딩된 텍스트 내부의 Base64 데이터를 추가 해독하는 중첩 해독 경로를 구성했습니다.
- 후속 2.3.1·2.3.2 패키지의 존재는 확인되지만, 해당 버전들은 개별 소스 스냅샷에 포함되지 않았습니다.

[전신 소스](history/kone-auto-decoder-v2.3.0.user.js)
